Network Optimisation · Dijkstra's Algorithm

Dynamic Evacuation Plan Model for Aboagye Menyah Complex at KNUST

BSc Project · Department of Mathematics, KNUST · with Alfreda Ofori Appiah · Supervisor: Prof. Peter Amoako-Yirenkyi · August 2023

Abstract

Safely evacuating people from a complex building during an emergency is a critical public-safety problem, and most existing evacuation plans rely on a single fixed route that can't adapt if that route becomes blocked. This project builds a detailed network model of the Aboagye Menyah Complex at KNUST — 43 nodes across a basement and four floors, including 9 marked exits — and formulates two optimisation problems over it: an offline model that finds the shortest route from any intersection to any exit, and a dynamic model that recomputes the shortest route around a set of blocked nodes in real time. Both are solved with Dijkstra's algorithm.

Methodology

The network was built from real measured distances between adjacent intersections, stairwells, and exits. The offline optimisation model minimises total distance from a source node to a destination node subject to flow-conservation constraints, giving a static evacuation plan for the whole building. The dynamic model solves the same problem while excluding a set of real-time blocked nodes, so it always returns a valid alternate route around an obstruction instead of defaulting to the original, now-invalid path.

Key result

Across two independent blocked-node scenarios, the dynamic model successfully recomputed a valid alternate route to the requested exit in every test case — never simply returning the original, now-invalid route.
