Linear Programming · Primal Simplex Method

Optimal Task Allocation using Modified Primal Simplex for KNUST Cleaning Staff

BSc Project · Department of Mathematics, KNUST · with Osman Inusah · May 2024

Abstract

Cleaning work in a large building is often handed out ad hoc, with no regard for how long each job takes or how the load is spread across staff. This project builds a linear-programming model that assigns cleaning tasks to workers across a sequence of time periods so that the longest period is as short as possible, and solves it with the primal simplex method. The case study is the Aboagye Menyah Complex at KNUST: 12 workers and 38 room-level cleaning tasks.

Methodology

Task times are estimated from the number of tiles, WCs and sinks in each room, with an exponential fatigue factor so that later tiles take longer to clean. The model then decides, for every worker, task and period, whether that assignment is made. Each task is completed in exactly one period, each worker takes exactly one task in every active period, and tasks longer than a 40-minute cap are split across several workers, which shortens the task proportionally. The objective is to minimise the longest time spent in any single period. Workers are assumed to have uniform skills and to collaborate with perfect efficiency.

Key result

For the 12-worker case study, all 38 tasks are completed in five periods totalling 174 minutes, with no single period longer than 39 minutes.
